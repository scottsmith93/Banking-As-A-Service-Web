# Portal / Client prototype pages

This folder contains the routes that are part of the active Portal/Client
prototype and should be included in localization review:

- Dashboard
- File management
- Project calculator
- Financial documents
- Year end meeting
- AI Advisor

English is the source and default language. Review these routes in English,
Spanish, French, German, and Portuguese at desktop and mobile widths.

Operational pages remain in their existing domain folders (`sales`,
`purchases`, `contacts`, `products-and-services`, `banking`, `accounting`,
`compliance`, and `settings`) and are intentionally outside this prototype
localization scope.
